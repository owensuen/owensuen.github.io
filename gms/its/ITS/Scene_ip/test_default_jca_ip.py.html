test_default_jca_ip.py

测试项描述

预检查项

  • Android 16 及更高版本中，scene_ip 场景支持执行默认相机应用和 Jetpack 相机应用（JCA）之间的图像一致性检查，以识别所捕获图像之间的主要差异。 JCA 会复现社交媒体应用的拍摄流程，提供基准参照图像供社交媒体应用进行后续处理和优化。

  • Android 16 以下（API LEVEL 小于 36）的设备不参与测试。

  • 平板（tablet）和桌面设备（desktop）不参与测试 [ro.build.characteristics]。

  • 多摄组合相机设备不参与测试。

  • 硬件配置要求：

    • scene_ip 测试需要在第 2 代相机 ITS 测试盒（Gen2 camera ITS-in-a-box）中进行。

    • 测试盒中集成的照明控制器和伺服控制器用于控制测试环境。

    • 测试盒内置一张特征检测标板。

    • [A17] 开始使用带 ArUco 标记的新版图卡。

测试内容与目标

在 ITS 测试盒的光照环境下，分别使用默认相机应用和 JCA（Jetpack 相机应用）对特征检测标板进行拍摄，并执行以下检查：

  • FOV 检查： 检查要求默认相机应用和 JCA 相机拍照 FOV 一致。 此项检测通过解析所拍摄的特征检测标板照片的中心的二维码计算 FOV 完成对比。

  • 亮度检查： 检查要求默认相机应用和 JCA 相机所拍照片的亮度差异小于 10。 此项检测使用动态范围测试卡进行亮度测量。

  • 白平衡检查： 检查要求默认相机应用和 JCA 相机所拍照片的白平衡差异小于 4。 此项检测使用动态范围测试卡进行亮度测量。

  • [A17] 色彩还原：检查默认相机应用和 JCA 之间的色彩还原差异（ΔE₇₆）不超过 6。

通过条件：FOV、亮度、白平衡测试全部判定合格。

在 Android 16 系统中，该检测 非强制要求（NOT_YET_MANDATED）。

[A17] 及更高版本，视场角、亮度和白平衡一致性检查为 强制要求。 色彩还原检查尚未强制要求。

此 ITS 测试项启动默认相机并拍照的方式：

（1）通过 ITSServer 获取 MediaStore.ACTION_IMAGE_CAPTURE 对应应用（即系统相机）的包名；

（2）通过 monkey -p pkg_name 1 启动系统相机，通过 input keyevent KEYCODE_CAMERA 触发拍照。

368718 孙海鑫 记录于 2025.11.11

异常描述

 
DEBUG Pattern matches
DEBUG Resource id: com.mediatek.camera:id/lens_switcher
DEBUG Flip camera content-desc:
DEBUG Closing app: com.mediatek.camera

异常原因

测试项判断当前的相机 facing 是通过 UI 中 Resource id: com.mediatek.camera:id/lens_switcher 控件的 Flip camera content-desc: 进行指示的，显然此时 content_desc 没有值。

lens_switcher 是 GoogleLens 的 UI 图标，camera_switcher 才是镜头切换图标的 id，且此图标的 UI 层级在 camera_switcher 之前，导致测试项匹配上了 lens_switcher 这个控件。

解决方案

修改 GoogleLens 的 UI 图标 id 为 btn_goto_google_lens，测试项 PASS
